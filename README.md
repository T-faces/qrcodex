# QRcodex

A simple web app to **generate** and **scan QR codes** using JavaScript.

## Features

- ✅ Generate QR code from text or link
- ✅ Scan QR code using webcam
- ✅ Works on mobile and desktop

## Tech Stack

- HTML, CSS, JavaScript
- [qrcodejs](https://github.com/davidshimjs/qrcodejs)
- [html5-qrcode](https://github.com/mebjas/html5-qrcode)

## Deployment

You can host this on GitHub Pages:

```bash
git clone https://github.com/t-faces/qrcodex.git
cd qrcodex
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/t-faces/qrcodex.git
git push -u origin main
